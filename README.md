## 🧠 Project Description
**Madam Ladies Wear** is a customized e-commerce platform built for a women’s fashion brand, allowing customers to browse, select, and purchase fashion products with ease. The platform includes a product catalog, shopping cart, and admin dashboard for managing inventory and orders.

The website is currently live in **partial format** and is actively under development. Future upgrades include backend migration to **Spring Boot** for enhanced scalability and performance.

---

## ✨ Key Features
- 🛍️ **Product catalog** with product details, images, and pricing  
- 🛒 **Shopping cart system** for a smooth purchasing process  
- 📊 **Admin dashboard** for managing products, orders, and inventory  
- 📱 **Responsive design** for seamless experience across all devices  
- 🔧 **Backend migration** to Spring Boot planned for improved scalability and performance
